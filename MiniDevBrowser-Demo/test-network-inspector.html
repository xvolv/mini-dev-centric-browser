🌐 Network Inspector Test Page

Open the Network Inspector panel in Mini Dev-Centric Browser to see all HTTP requests captured.

🎯 WHAT TO DEMO IN NETWORK INSPECTOR:
- ✅ All HTTP methods (GET, POST, PUT, DELETE, PATCH) are captured
- ✅ Request headers (Authorization, Content-Type, Custom headers)
- ✅ Response headers (Server, Cache-Control, Content-Type)
- ✅ Request body (for POST/PUT/PATCH requests)
- ✅ Response body (JSON formatted)
- ✅ Status codes (200, 201, 204, 404)
- ✅ Filtering by method, URL, status
- ✅ Export network logs
